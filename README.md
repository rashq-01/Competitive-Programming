## 🚀 How to Use

Clone the repository:

```bash
git clone https://github.com/rashq-01/Competitive-Programming.git
```

Move into the repository:

```bash
cd Competitive-Programming
```

Compile a solution:

```bash
g++ -std=c++17 solution.cpp -o solution
```

Run it:

```bash
./solution
```

For example:

```bash
g++ -std=c++17 28_1730C_Minimum_Notation.cpp -o solution
./solution
```
